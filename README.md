# Shell Scripting Lab 🧠

> 🚀 A collection of **practical bash and shell scripts** created while learning and exploring automation tasks commonly used in real-world DevOps environments.

---

## 🎯 Goals
- Strengthen scripting fundamentals for DevOps  
- Learn to automate day-to-day operational tasks  
- Build a reusable library of scripts for real project use  
- Practice production-ready scripting standards (logging, parameters, error handling)

---

## 📂 Structure
- **system/** - OS-level checks, cleanup, monitoring  
- **automation/** - Backup, restore, deploy, and cron jobs
- **user/** - User and permission management
- **git/** - Git automation scripts 
- **docker/** – Common container management commands(future scope)  
- **cicd/** - Scripts for Jenkins/GitHub Actions pipeline tasks(future scope)
- **misc/** - Miscellaneous or experimental scripts(future scope)
