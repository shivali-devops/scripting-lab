# 🐳 Docker Scripts

Scripts for **container lifecycle management and cleanup**.

---

## 📜 Included Scripts
| Script | Description |
|--------|--------------|
| `cleanup_docker.sh` | Removes unused containers, images, and volumes |
| `docker_healthcheck.sh` | Checks container health status |
| `build_run_image.sh` | Builds and runs a Docker image |
| `remove_old_images.sh` | Prunes unused Docker images |

---

> 💬 Supports container maintenance and optimization in local or production environments.
