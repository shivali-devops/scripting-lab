# System Scripts

Scripts for **system monitoring, resource checks, and cleanup automation**.

---

## 📜 Included Scripts
| Script | Description |
|--------|--------------|
| `cpu_usage_check.sh` | Monitors CPU usage and alerts if threshold crossed |
| `memory_check.sh` | Displays memory utilization |
| `disk_cleanup.sh` | Removes temporary/log files older than a defined limit |
| `system_health_report.sh` | Prints summary of CPU, memory, and disk stats |

---

> 💬 These scripts help maintain system stability and visibility in production environments.
