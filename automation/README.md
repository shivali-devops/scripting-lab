# ⚙️ Automation Scripts

Scripts for **backups, restores, log rotation, and scheduled maintenance**.

---

## 📜 Included Scripts
| Script | Description |
|--------|--------------|
| `backup_files.sh` | Backs up important files or directories |
| `restore_backup.sh` | Restores backups safely |
| `log_rotate.sh` | Compresses and archives logs periodically |
| `deploy_app.sh` | Automates application deployment steps |

---

> 💬 Focused on replacing repetitive manual tasks with automated, reliable workflows.
