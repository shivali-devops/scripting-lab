# User Management Scripts

Scripts for **user creation, permissions, and security checks**.

---

## 📜 Included Scripts
| Script | Description |
|--------|--------------|
| `create_user.sh` | Adds a new user with permissions |✅ 
| `remove_user.sh` | Removes a user safely |
| `list_users.sh` | Lists all normal (non-system) users on the system.|
| `list_active_users.sh` | Lists logged-in users |
| `check_sudo_access.sh` | Verifies users with sudo privileges |

---

> 💬 Helps automate user access control for secure, consistent environments.
