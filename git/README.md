# Git Utility Scripts

Scripts for **automating Git operations** in DevOps pipelines.

---

## 📜 Included Scripts
| Script | Description |
|--------|--------------|
| `auto_commit_push.sh` | Auto stages, commits, and pushes changes |
| `branch_cleanup.sh` | Deletes merged branches |
| `repo_status.sh` | Displays current repo info (branch, status, etc.) |

---

> 💬 Simplifies repetitive Git operations during development and CI/CD.
